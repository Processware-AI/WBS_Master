# WBS Master — 일정관리 및 통제 웹 애플리케이션

`일정관리및통제결과표(2026년 템플릿).xlsx` 의 구조와 수식을 웹으로 옮긴 프로젝트 일정관리·진척통제 도구입니다.

## 실행

```bash
python3 server.py            # → http://localhost:8080
python3 server.py 8080 0.0.0.0   # 같은 네트워크의 팀원과 공유
```

- 데이터는 `data/wbs-data.json` 에 자동 저장되고, `data/backup/` 에 5분 간격으로 백업이 남습니다.
- 서버 없이 `index.html` 을 바로 열어도 동작합니다(이 경우 브라우저 localStorage 에 저장).
- 외부 인터넷 연결 없이 동작합니다(엑셀 라이브러리 `vendor/xlsx.full.min.js` 포함).

## 엑셀 시트 ↔ 화면

| 엑셀 시트 | 웹 화면 |
|---|---|
| 표지 / 문서승인 / 제개정이력 | 표지·승인·제개정이력 |
| 진행현황_전체 (점검마감일자, 범위별 가중치·현황, 그래프) | 전체 진행현황 (대시보드) |
| 진행현황_01~10 (단계별 가중치·현황, Review 문서) | 범위 › 진행현황 |
| 진행율 입력_01~10 (WBS, 진척 입력, 주간 간트) | 범위 › 진행율 입력 (WBS), 범위 › 간트차트 |
| 휴일 리스트 | 범위·가중치·휴일 |
| 인쇄 | 보고서 인쇄 (A4 가로, PDF 저장 가능) |

## 계산 규칙 (엑셀 수식과 동일)

- 계층: 범위(가중치 합 100) → 단계(범위 내 합 100) → 태스크(단계 내 합 100)
- 계획진척 = 점검일 ≥ 계획종료 ? 100% : 점검일 < 계획시작 ? 0% : 경과 영업일 ÷ 계획 영업일
- 가중치계획 = 가중치 × 계획진척 / 100, 가중치실적 = 가중치 × 실제진척 / 100, 편차 = 실적 − 계획
- 진행상태: 편차 < 0 → 지연, 실제진척 100% → 종료, 그 외 진행 (둘 다 0이면 미착수)
- 단계 시점 누적계획 = Σ가중치계획 × 단계가중치, 범위 누적계획 = Σ단계, 전체 = Σ(범위 × 범위가중치/100)

엑셀 원본과 다른 점:
- 원본의 계획진척 수식은 경과일을 `DAYS360`(30일 기준 달력일)으로 세고 계획기간은 `NETWORKDAYS`(영업일)로 세서, 진행 중인 태스크의 값이 영업일 기준과 어긋납니다. 이 앱은 둘 다 영업일로 계산합니다.
- 원본의 CP 수식은 선행 태스크의 `진행상태` 열을 참조하고 있습니다(`VLOOKUP …,15`). 이 앱은 선행 태스크의 계획종료일과 이 태스크의 계획시작일 사이 영업일 수를 구합니다. 0이면 바로 이어지고, 음수면 일정이 겹칩니다.
- 일정준수여부(O/X)는 원본처럼 손으로 입력하지 않고 실제종료일과 계획종료일을 비교해 자동으로 판정합니다.

## 추가 기능

- 범위·단계·태스크 개수 제한 없음, 행 삽입/복제/이동, 실행 취소(Ctrl+Z)
- 점검 결과 저장 → 실적 추이 S-커브, 지연 태스크·2주 내 시작 예정 목록
- 원본 템플릿 엑셀 가져오기, 같은 시트 구성으로 엑셀 내보내기, JSON 백업/복원
- 여러 프로젝트 관리, 다크 모드
